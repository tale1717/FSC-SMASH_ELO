On a player profile, open **Stats → Elo progression** to see the rating after each attended tournament, set W–L and any recorded bracket placement. This uses published set deltas, including matches against players who do not qualify for the official ranking. Placements are captured when supplied by a normal import. Cached older brackets can have no placement; the chart never infers one from Elo.

In the organizer results editor, load saved results, select the saved tournament, then choose **Check tournament status → Finalize tournament**. Finalizing preserves published Elo and set history. Its rooms leave the active lists and appear in the archive. Reopening allows corrections and makes unfinished, unexpired rooms available again. Approved and expired rooms stay archived. Fall Bracket #6 starts finalized. Tournament status survives importer runs and is separate from undoing an edit.

Deploy Firestore rules and Hosting, then update the existing Cloudflare Worker from cloudflare-worker/worker.mjs. No migration, new binding or import is needed. The public status document contains only bracket slugs and boolean flags. Worker list/poll requests reuse the status for up to 15 seconds per Worker instance; mutations check current status. This feature uses Firebase and Cloudflare, not the Challonge API.
