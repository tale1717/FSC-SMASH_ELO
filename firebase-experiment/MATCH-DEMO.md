# Match reporting demo

Open public/match-demo.html or the main-page demo link. Demo codes ELO-A1 and ELO-B1 simulate separate players on one device. They are public examples, not live credentials. Refresh resets all data; no network requests, reporting writes or Elo updates occur.

The demo covers game-by-game characters (sample menu), mutual agreement, randomized opening 1–2–1 striking, three winner bans, unrestricted stage repeats, player confirmations, pending TO message, TO approval and correction. Best of three is an example. Stage pictures are pending.

Not production-ready: live match synchronization, private server-generated single-use codes, temporary player sessions, role-enforced actions, cross-device synchronization, secure admin login, persisted reports, expiry/rate limits and full roster/best-of rules must be implemented before using this for actual results. Do not remove the demo label or reuse the hard-coded example codes in a real match flow.
